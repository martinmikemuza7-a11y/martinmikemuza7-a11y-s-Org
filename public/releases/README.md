# StudyBuddy AI Release Artifacts (v1.0.0)

This directory contains standalone installable distribution packages for StudyBuddy AI:

- `studybuddy-ai-v1.0.0.apk` — Android installable release APK
- `StudyBuddyAI-Setup-1.0.0.exe` — Windows standalone NSIS installer
- `release-info.json` — Checksums and verification metadata

To compile these binaries directly from source:
- Android: `npm run build:android`
- Windows: `npm run build:windows`
- Web PWA: `npm run build:pwa`
